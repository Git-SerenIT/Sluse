Delete the copies in your box?

This deletes every copy Sluse let into this box when an AI agent fetched a file, from every session. It removes those files, not the record of them.

Goes

  • The provenance file beside each copy
  • Downloads that did not finish

Stays

  • The record of every admission, in this box and on your computer
  • What was published, in Sluse Artifacts
  • The files at their sources

An AI agent can ask Sluse for a file again later. That is a new admission, recorded like the first.
