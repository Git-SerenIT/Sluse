    Set up Sluse for your organisation

    Sluse Admin makes Sluse's app registration in your tenant, helps you write one configuration for one deployment, and hands it to Intune. It reads your directory as you, and keeps its token in this window only.

    Sign in as your tenant's administrator

    You sign in as Microsoft Graph Command Line Tools, Microsoft's own app, so nothing needs registering first. Its consent page asks for what setup does as you.

    Leave "Consent on behalf of your organization" unticked. Ticked, it grants these permissions to that app for everyone in your tenant, not just for this setup.

    What the consent page asks for
    • Make and repair Sluse's app registrationApplication.ReadWrite.All
    • Assign a group of people to Sluse's appAppRoleAssignment.ReadWrite.All
    • Find groups and read your rolesDirectory.Read.All
    • Browse SharePoint sites to pick sourcesSites.Read.All
    • Add Sluse's app to IntuneDeviceManagementApps.ReadWrite.All

    Each is used as you, so Entra still decides by your own roles.

    If your tenant blocks Graph Command Line Tools

    Microsoft's page then shows AADSTS7000112 (the app is disabled) or AADSTS50105 (you are not assigned to it). Allow the app for this setup in Enterprise applications, or run the setup from a command prompt with a public client of your own:

    sluse admin setup --client-id <your public client's id>

          Publish

          One Intune app carries Sluse and this configuration. Save it here, then upload it to Intune by hand, or publish it straight from here.

          1. Sluse.msi

            Pick the Sluse.msi the app carries: the one you installed Sluse Admin from, or a newer release to move devices to it.

            Cancelling the Open dialog keeps this one.

          2. Save the configuration and its package

            Waits for Sluse.msi.

            Saving runs the box's check first, then writes the configuration, a package folder and one .intunewin side by side. Reading and packing the MSI takes a few seconds.

          3. Or publish straight to Intune

            Needs an Intune Administrator. Uploads a saved package as one app, assigned, required, to a device group. A new revision supersedes the last as an update.
